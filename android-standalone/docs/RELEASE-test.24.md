# Wormwright Pocket 0.1.0-test.24

NAS settings now match Notes: plain NAS IP address, share name, folder within share, username, optional domain and password. Defaults match Notes. Folder errors are shown on the folder field rather than claiming the IP address format is wrong. Password masking, saved-password retention and autofill protections remain.

Settings and backup-password dialogs size their scrolling content to the available screen and keyboard space, keeping Cancel and the action buttons visible. Install over the current app without uninstalling.
