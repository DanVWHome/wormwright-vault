# Wormwright Pocket branding

Approved by Dan on October 9, 2026. Name: **Wormwright Pocket**.
Tagline: **Your personal password vault**. Platform neutral for future iOS use.

Icon: `app/src/main/res/drawable-nodpi/pocket_icon.png`. Generated with the
built-in image tool using the existing Vault mascot and Wormwright AI Mascots
reference; original reference files were unchanged.

Prompt: Preserve the cheerful coral-orange Wormwright face, big white eyes, navy
outlines, shaded cartoon finish and cream AI sparkle badge. Put Wormwright inside
a navy-blue fabric pocket with cream stitched seams, head and upper neck peeking
out and badge visible above the rim. Hide the lower body naturally inside the
pocket. Attach the familiar gold padlock with silver shackle prominently to the
front of the pocket. One worm, one pocket, one lock; no extra objects or text
except the AI badge. Square transparent icon with comfortable margins and a
complete pocket silhouette, matching the existing Vault artwork.
