# Wormwright Vault Android 0.1.0-preview.11

New and existing entry editors now offer Generate password. It uses secure random data and the desktop-compatible 24-character CSV-safe alphabet: no commas, quotation marks or line breaks. Generated passwords remain hidden unless Show password is selected; Save commits the change and Cancel discards it. Existing named vaults, separate NAS settings, sync and authentication are retained. Install over preview.10 without uninstalling.
