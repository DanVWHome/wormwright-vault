# Reporting security vulnerabilities

Please use [GitHub private vulnerability reporting](https://github.com/DanVWHome/wormwright-vault/security/advisories/new)
for a suspected security vulnerability. A GitHub account is required.
Do not report vulnerabilities in public issues or attach real vaults, passwords,
recovery codes, YubiKey PINs or NAS credentials. Include affected versions,
reproduction steps using synthetic data and the potential impact.

For ordinary bugs, use the bug-report issue form. Reports are reviewed by the
maintainer; no response time or formal support period is guaranteed.
