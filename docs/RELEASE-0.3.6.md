# Wormwright Vault 0.3.6

New vaults require a human-readable name. Vault → Rename Current Vault names existing vaults; only an unlocked Manager can change the shared name. Vault → Recent Vaults lists names and exact file paths. Names are independently Manager-signed metadata preserved in encrypted vault backups and NAS synchronization without changing format-2 account or entry encryption. Display names are visible metadata; avoid secrets in names. Older unnamed vaults remain readable and can be named explicitly.

Vault → Delete Current Local Vault reviews its name and exact path, with fresh authorization and typed DELETE. Cancel remains available. Other deletion and backup cleanup options from 0.3.5 are retained.
