# Wormwright Vault 0.3.7

Choosing Use Password after YubiKey immediately focuses the account password field on Windows and Linux, in both Vault and Vault Manager. Typing can begin without an extra mouse click.

Windows embeds the existing Wormwright Vault artwork in the executable and installer, assigns the application a stable taskbar identity, and uses the matching Vault/Manager icons for Start menu shortcuts. Desktop shortcuts and the installed-app listing use the embedded Vault icon. No vault format or authentication changes. Install over the existing version to preserve vaults and settings.
