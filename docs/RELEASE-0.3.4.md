# Windows 0.3.4 preview 1

Help → Check for Updates checks the selected stable or preview channel. Help → Update Settings controls the channel and optional once-daily checks while the app runs. Automatic checks are off initially. Checks send no vault, account or search data. Download Update opens the official Windows page; close both apps and run the newer installer over the existing installation. Vaults and settings are retained. No automatic download or installation is performed.
