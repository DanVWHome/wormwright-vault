# 0.3.9 — four named YubiKeys

Add up to four independent keys per vault account without replacing existing
keys. Named key selection works for unlock and hardware reauthentication.
Add YubiKey and Manage YubiKeys provide enrollment, rename and removal. Existing
single-key enrollments are preserved. See FOUR-YUBIKEYS.md for update order,
backup/offline-copy limitations and mobile companion versions.
