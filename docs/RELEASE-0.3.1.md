# Wormwright Vault 0.3.1

Desktop search now includes usernames in Vault, Manager and the companion window. Existing description, website and notes searches remain available. Passwords are excluded from search.

Example: an entry named Email with username mouse now appears when searching mouse.

Close Vault and Manager before installing the Linux Mint amd64 package. Existing beta shortcuts continue to work. Test username search and NAS synchronization on this computer before publishing or updating other machines. GitHub publication and website changes are deferred until acceptance.
