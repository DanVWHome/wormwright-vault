# Wormwright Vault 0.3.14 — adjustable desktop columns

Drag a divider between column headings to resize it, or double-click it to fit
the contents. Widths are remembered on this computer and survive filtering,
sync, locking and reopening. Vault, Vault Manager and secondary views use
adjustable columns. Long links display on a single line, and hovering over a
link shows its complete address. Password masking is retained.

Adds a second built-in family permissions demo on desktop and Android
companion preview.24. Existing demos remain available. Desktop Searchable Help
includes the complete family guide and explains that Manage appears only after
unlocking as the actual vault Manager, not merely opening the Manager app.
Android offers account switching, reset and offline family-demo instructions.
Adds Manager-only Rename Group in Users & Groups. Renaming keeps the group’s identity, members, entries, exclusions and default-group selection. Ownership and shared view-only permissions from 0.3.13 are retained.
Mint is published first for device testing. Windows and Fedora follow only
after the owner's confirmation.
