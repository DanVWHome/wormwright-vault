# Wormwright Vault 0.3.14 — adjustable desktop columns

Drag a divider between column headings to resize it, or double-click it to fit
the contents. Widths are remembered on this computer and survive filtering,
sync, locking and reopening. Vault, Vault Manager and secondary views use
adjustable columns. Long links display on a single line, and hovering over a
link shows its complete address. Password masking is retained.

Ownership and shared view-only permissions from 0.3.13 are unchanged. Android
companion preview.23 remains compatible; it needs no update for desktop columns.
Mint is published first for device testing. Windows and Fedora follow only
after the owner's confirmation.
